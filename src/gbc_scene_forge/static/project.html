GBC budgets

Checks the current canvas against 8 background/window slots and 8 sprite slots. Includes hidden layers and all frames of animations linked to placed artwork.

Reserve slots for UI/window content, effects and dynamic actors. Leave blank if unknown; enter zero only when no additional slots are needed. Unknown reservations cannot pass preflight.

Optional tile and sprite estimates

Static layout: BG bank 0, OBJ bank 1; 256 8×8 tiles each. All layers and animation frames resident; no pixel deduplication or camera culling. Blank reservations mean unknown.

GBC palette checks are off.

Assumes static residency without palette streaming. Preview playback does not affect counts. A pass covers this palette budget; the game build must verify its remaining requirements. Generic Tiled export stays available.
