# Representative scene briefs and observable checks

Run authoring evaluations in selected disposable projects. These briefs test
decisions and observable outcomes; they are not required output templates.
Synthetic tool replays establish data/guard behavior, not model adherence or
visual quality. Record actual client/version, candidate snapshots, images seen,
refinements, saved revisions and export/reopen scope for real authoring runs.

| Brief | Expected decisions and observable checks |
| --- | --- |
| “Plan a 256×128px room on an 8px grid, 64×64 camera, floor, spawn, exit and optional upper route. No artwork. Save and export.” | Create blockout with explicit pixel units; discover typed presets; dry-run edits; inspect SVG overview/camera before save. Reopen exported project and compare geometry, IDs, camera and definitions. Do not certify jumps or reachability. |
| “Use my existing terrain and lantern to dress the entry; keep the plan and connections. Show a draft first.” | Inspect inventory, grid, origin, ordered layers and world endpoints. Paint cells and place anchored sprite narrowly in a dry-run candidate. Inspect PNG and blockout, native details and whole composition; no save/export of the candidate until requested. Preserve unrelated layers/assets/objects/world. |
| “Draw a new 8×8 beacon, place it above the gate, save and export this scene.” | Follow artwork skill's actual inspection/receipt commit; refresh inventory and scene bases before placement. Review artwork-inclusive scene and plan before guarded save; export scene ZIP, import/preflight/reopen separately. A commit can re-encode maps; never reuse stale guards. |
| “Repeat this saved arch stamp twice, then adjust the right prop and check the whole level.” | Discover stamp; hand off to browser stamp palette because placement is absent in this profile. Read fresh saved scene afterward; preserve layer slots/new IDs, full extent and other props. Browser Diagnostics and combined Scene view complete absent MCP operations. |
| “Use a terrain brush, change preview preferences and import this Tiled map.” | Follow the outcome routes and use explicit browser import/preflight, Terrain and preview flows. Do not simulate semantic terrain resolution or claim settings writes through save_scene. |
| “Another tab changed the exit while you were arranging tiles.” | Preserve old candidate, compare fresh saved content and deliberately rebuild only intended changes. Review again. Stale guard save rejects and unrelated exit survives. Lost acknowledgment triggers inspection before another write. |
| “Export my long level including everything.” | Confirm saved scope versus browser drafts/artwork handles; inspect paged PNG coverage and full planning overview. Download immutable ZIP and reopen separately; oversized MCP resource uses browser. Report unavailable visual/reopen checks explicitly. |

Failure cases include unavailable images (disclosed browser review), cropped
overviews (additional views), missing tools (browser handoff), and stale bases
(no hash substitution or destructive replay). Scene review success never replaces
visual inspection, and browser handoff never transfers unsaved scene ownership.
