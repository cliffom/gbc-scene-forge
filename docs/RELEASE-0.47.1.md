# GBC Scene Forge 0.47.1

The Codex plugin now shows `0.47.1` in **About → Version**, matching GitHub tag
`v0.47.1` and the bundled Forge runtime. The release workflow checks version
alignment before asking for macOS signing approval.

## Upgrade and compatibility

The plugin preview supports local Codex on Apple Silicon with macOS 27 or newer.
Refresh **GBC Scene Forge builds** in the marketplace and install the updated
listing. Start a new Codex chat after updating, then reopen your game folder.
See the [plugin update guide](PLUGIN-DISTRIBUTION.md#update-and-rollback).

The project and selection formats remain at version 1. The standalone wheel
requires Python 3.10 or newer. The wheel, source archive, and macOS bundle are
distributed through the [GitHub release](https://github.com/cliffom/gbc-scene-forge/releases/tag/v0.47.1).
