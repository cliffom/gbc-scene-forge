# Changelog

Release changes and upgrade boundaries live in the versioned notes linked below.
Their commands and feature scope describe their historical version; use the
[standalone reference](STANDALONE.md) for current behavior. Observed checks belong
in [validation](VALIDATION.md), priorities in the [roadmap](ROADMAP.md), and build
and publication procedures in [releasing](RELEASING.md).

## 0.40.0 — Focused artwork setup and agent drafts

[Release notes](RELEASE-0.40.0.md). Separate New artwork, Existing artwork and
From agent into padded keyboard tabs. Keep creation first, browse agent drafts
visually, preview without downloading, and explicitly edit an independent copy.
Hide editing commands until an editable document opens; keep PNG and snapshot
JSON downloads separate. Saved bases, review, histories and recovery remain guarded.
Publication is separate.

## 0.39.0 — Drawing space and native PNG downloads

[Release notes](RELEASE-0.39.0.md). Start with drawing space, retain deliberate
pane/dock choices, carry tool letters across scenes and artwork, and download
current artwork or a selected frame as native PNG. Add goal-based starts and
Library stamp creation; prioritize Inspector editing/preview and keep routine
open/save feedback below the canvas. Publication is separate.

## 0.38.0 — Editor discovery and drawing scope

[Release notes](RELEASE-0.38.0.md). Put artwork search and browsing ahead of
source management, expose Open scene in the empty workspace, and keep drawing
scope beside the tools. Fresh named poses open in Frame scope; retained artwork
keeps its deliberate scope. Publication is separate.

## 0.37.0 — Close active documents

[Release notes](RELEASE-0.37.0.md). Close the active scene or artwork from the
shared document bar. Save, retain a recovery draft, explicitly discard or cancel
modified work; artwork keeps its review-and-confirm flow. Closing preserves saved
assets and unrelated retained documents. Publication is separate.

## 0.36.1 — Follow saved artwork updates

[Release notes](RELEASE-0.36.1.md). Clean open artwork follows committed MCP
updates automatically, retaining valid review context and clearing old history.
Manual edits pause replacement with download and explicit load-latest actions.
Background refresh failures retry quietly before surfacing inline. Publication
is separate.

## 0.36.0 — Selective MCP pixel cleanup

[Release notes](RELEASE-0.36.0.md). Analyze small color islands, preview only
selected suggestions and validate exact protected-pixel, layer, alpha and palette
constraints. Review source PNGs and native change maps before the existing guarded
commit. Artistic intent, outline repair and plane consolidation remain unverified
or unsupported. Publication is separate.

## 0.35.0 — MCP illustration iteration and review

[Release notes](RELEASE-0.35.0.md). Compare explicit artwork drafts, request
coordinate-labelled PNG inspection sheets, and plan deliberate candidate archives
using exact saved-content evidence. Preserve saved-base review receipts, existing
SVG defaults and durable export-before-release. Publication is separate.

## 0.34.0 — MCP illustration preparation and lifecycle

[Release notes](RELEASE-0.34.0.md). Add storage visibility and durable explicit
candidate archiving, independent native resize/canvas preparation, opt-in palette
conversion, aligned layer intake, portable artwork output, atomic candidate edit
batches and revision-bound coordinate contact sheets. Preserve native envelopes,
exact layers and separate reviewed commits. Publication is separate.

## 0.33.3 — Faster artwork opening and layer changes

[Release notes](RELEASE-0.33.3.md). Reduce repeated raster comparisons and native
verification during artwork opening and visibility changes. Library opens show
a named, cancellable loading state; failed reads can be retried without losing
retained documents. Publication is separate.

## 0.33.2 — Dismissible editor notifications

[Release notes](RELEASE-0.33.2.md). Replace transient artwork, scene and project
status text with shared top-right notification cards. Routine notices expire or
can be dismissed; save and recovery failures persist until acknowledged or
resolved. Locked-layer warnings coalesce and explain how to resume editing.
Publication is separate.

## 0.33.1 — Library source actions and layer controls

[Release notes](RELEASE-0.33.1.md). Wrap long source names in Library rows and
move source update/delete actions from Inspector into Library. Layer visibility
and locking apply immediately with independent Undo steps, while pending name
and opacity entries survive flag changes. Publication is separate.

## 0.33.0 — Unified scene and artwork editor

One document control now navigates scenes and retained artwork, preserving local
editing context and showing local state separately from detected external changes.
One Save location and shared command strip follow the active document; artwork
retains exact review and explicit confirmation.

[Release notes](RELEASE-0.33.0.md). Share the Library, workbench, collapsible
Inspector and optional frame/animation dock. Contextual source actions distinguish
shared edits, independent copies and selected-placement variations; disappeared
copy sources stay unavailable without clearing entered fields. Single-tile
repetition previews update with painting, history and document switching. Preserve exact
review, independent histories and browser/MCP recovery guards. Publication is separate.

## 0.32.0 — Human–agent artwork iteration

[Release notes](RELEASE-0.32.0.md). Add direct editable PNG intake, bounded inline

while Artwork is open, and pointer-anchored wheel zoom. Publication is separate.

Publication is separate.
