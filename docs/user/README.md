# User tutorials

These tutorials walk through complete authoring tasks. For supported features,
limits and file-format details, see the [standalone reference](../STANDALONE.md).

| Tutorial | What you will build |
| --- | --- |
| [Create and edit pixel artwork](pixel-artwork.md) | Native tiles/static sprites with drawing tools, scene review and recoverable drafts |
| [Create your first level blockout](blockout-tutorial.md) | An artwork-free forest plan with terrain, encounters, progression markers and a configurable camera view |

For agent-assisted authoring, see [Local MCP authoring](../MCP.md) and its reproducible SDK-client example.
