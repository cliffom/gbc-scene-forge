# GBC Scene Forge 0.48.0

Open a project to arrange its scenes in World desk. Double-click a card or
choose **Open scene** to edit. **Back to world map** restores the map camera
and selected scene while retaining unsaved scene edits and Undo history.

Existing projects open directly, and bookmarked scene links still open their
saved scenes. World placement uses the existing guarded **Save world** operation.
See the [world navigation guide](STANDALONE.md#world-view-and-scene-connections).
